# 元智 Portal 手機版 · YZU Portal Mobile

把元智大學 Portal 變成手機好用的介面。**免費、非官方，不用給帳號密碼。**
A phone-friendly version of Yuan Ze University's Portal. **Free, unofficial, no password sharing.**

## 安裝 · Install

**👉 https://jacksight.github.io/yzu-portal-mobile/**

- **iPhone**：Safari + 免費的 Userscripts 擴充功能，登入 Portal 就自動變成手機版
  Safari + the free Userscripts extension; log in to the Portal and it turns mobile
- **Android**：下載 App · download the app →
  [yzu-portal.apk](https://github.com/jacksight/yzu-portal-mobile/releases/latest/download/yzu-portal.apk)

## 安全 · Safety

- 帳號密碼只在學校自己的登入頁輸入，沒有任何伺服器在中間幫你登入
  You only type your password on the school's own login page; no server logs in for you
- 資料直接在你的手機和學校之間傳 · Data goes straight between your phone and the school
- 只匿名統計使用人數（不含學號或任何個人資料）· Usage is counted anonymously (no student ID or personal data)
- 非官方工具，與元智大學無關 · Unofficial, not affiliated with Yuan Ze University

## 功能 · Features

首頁待辦／通知／公告、中英切換、快速連結、課程（公告留言、教材、作業、成績、成員、課程內容）、成績、課表、考試、出缺勤、全校課程查詢、社團、設備／場地預約。
Home (to-dos, notifications, news), 中文/English, quick links, courses (posts & comments, materials,
homework, scores, members, syllabus), grades, timetable, exams, attendance, course search, clubs,
equipment / venue booking.
